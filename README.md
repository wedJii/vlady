# 🎮 vlady (Вкусные рогалики)

## 📥 Как скачать и запустить игру другу

### Вариант 1: Скачать архив игры (быстрее и проще всего)
👉 **[Скачать архив vlady_Windows_x64.zip (49 MB)](https://github.com/wedJii/vlady/releases/download/v1.0.0/vlady_Windows_x64.zip)**
*(или скачайте из папки [`Build/vlady_Windows_x64.zip`](Build/vlady_Windows_x64.zip) в репозитории)*

1. Скачайте архив по ссылке выше.
2. Распакуйте архив в любую удобную папку.
3. Запустите файл **`vlady.exe`**.
4. Играйте!

---

### Вариант 2: Готовая папка с игрой в репозитории
Все файлы билда также доступны прямо в папке:
👉 **[`Build/vlady/`](Build/vlady/)** (включая **`vlady.exe`**).
